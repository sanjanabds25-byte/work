Web Development Basics - click a question to see the answer

HTML (HyperText Markup Language) is the standard language used to create the structure of a web page using headings, paragraphs, images and links.
CSS (Cascading Style Sheets) is used to style web pages. It controls colours, fonts, spacing and layout.
JavaScript is a programming language that makes web pages interactive, handles button clicks and updates content without reloading the page.
Tailwind CSS is a utility-first CSS framework that lets developers style web pages using ready-made utility classes.
DOM (Document Object Model) represents a web page as a tree of objects. JavaScript can use it to change page content and styles.
